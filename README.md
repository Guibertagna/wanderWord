# WanderWord

**WanderWord** é um projeto de **Trabalho de Conclusão de Curso** (TCC), desenvolvido com **Angular + Ionic** e utilizando o **Firebase** como backend.

## 📚 Sobre o Projeto

O objetivo do WanderWord é oferecer uma experiência prática de leitura e anotação em arquivos PDF. O usuário pode:

- 📤 Fazer **upload de arquivos PDF**
- 📝 Realizar **anotações** diretamente no documento
- 💾 **Salvar** essas anotações de forma persistente na nuvem

## 🚀 Tecnologias Utilizadas

- **Angular**
- **Ionic Framework**
- **Firebase** (Authentication, Firestore, Storage)
